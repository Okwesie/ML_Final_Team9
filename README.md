## 🚀 Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the Notebook

1. Open `Team_9_Final_Project.ipynb`
2. Run all cells from top to bottom
3. This creates `models/` and `outputs/` directories

### 3. Start the App

```bash
streamlit run app.py
```

The app will open at `http://localhost:8501`

### 4. Load Models & Data

In the app sidebar:
- Click **"🔄 Load Models"**
- Click **"📊 Load Data"**

## 🔗 How Notebook and App Connect

### Simple Explanation:

1. **Notebook** = Training & Analysis
   - Loads data
   - Trains ML models
   - Generates insights
   - Saves models and outputs

2. **App** = Deployment & Interaction
   - Loads saved models
   - Provides interactive UI
   - Shows recommendations
   - Displays insights

### Connection Flow:

```
Notebook runs → Creates models/ & outputs/ → App loads these files → User interacts
```

**Key Files:**
- `models/*.pkl` - Trained models (saved by notebook, loaded by app)
- `outputs/*.csv` - Data files (generated by notebook, displayed by app)
- `outputs/*.json` - Metrics (created by notebook, shown in app)

## 🔧 Troubleshooting

### Common Issues:

**"Models not found"**
- Solution: Run the notebook first to create models/

**"Data not found"**
- Solution: Run the notebook to generate outputs/

**App won't start**
- Solution: Install dependencies: `pip install -r requirements.txt`

**Port already in use**
- Solution: Use different port: `streamlit run app.py --server.port 8502`

See **QUICK_START.md** for detailed troubleshooting.
